Prism Browser เป็นโปรแกรมจัดการโปรไฟล์เบราว์เซอร์บนเครื่องที่ปรับแต่งลายนิ้วมือดิจิทัลได้ โดยใช้ Chromium ที่ปรับแต่งมา แต่ละโปรไฟล์มีคุกกี้ แคช ข้อมูลส่วนขยาย การตั้งค่าพร็อกซี และลายนิ้วมือแยกจากกัน จึงใช้จัดการตัวตนเบราว์เซอร์หลายชุดได้อย่างเป็นอิสระ

ตามค่าเริ่มต้น โปรไฟล์ คุกกี้ ข้อมูลรับรองพร็อกซี และประวัติการท่องเว็บจะอยู่บนอุปกรณ์ของผู้ใช้ รุ่น Community ใช้ฟรีและไม่จำกัดจำนวนโปรไฟล์ในเครื่อง

## นโยบายดูแลซอร์สโค้ด

คลังโค้ดนี้จะยังเปิดเผยสำหรับการศึกษา ตรวจสอบ และบิลด์โดยชุมชน ตั้งแต่ `v0.3.17` เป็นต้นมา ฟีเจอร์ การแก้ไข และซอร์สโค้ดของผลิตภัณฑ์จะไม่ถูกซิงก์มาที่นี่เป็นประจำ เนื่องจากความซับซ้อนของแอป เอนจิน แพ็กเกจหลายแพลตฟอร์ม และฟีเจอร์ Pro ทำให้การดูแลและทดสอบหลายสาขามีต้นทุนสูงขึ้น

การอัปเดตครั้งนี้เป็นข้อยกเว้น โดยนำระบบหลายภาษาทั่วไปจาก 0.3.19 มาใช้และแปลอินเทอร์เฟซสาธารณะที่มีอยู่ ไม่รวมรันไทม์ส่วนตัวของ Pro บริการออกสิทธิ์ใช้งาน ฟีเจอร์ Pro ใหม่ หรือการตั้งค่าการเผยแพร่ส่วนตัว และไม่ได้หมายถึงการกลับมาซิงก์ซอร์สโค้ดผลิตภัณฑ์อย่างต่อเนื่อง

โค้ดเดิม ประวัติคอมมิต และรุ่นเก่าจะยังอยู่ ดูฟีเจอร์ การแก้ไข และตัวติดตั้งล่าสุดได้ที่[เว็บไซต์ทางการ](https://prismbrowser.app/) และ [Releases](../../releases)

## ภาษา

อินเทอร์เฟซและ README รองรับ **13 ภาษา** ได้แก่ จีนตัวย่อ จีนตัวเต็ม อังกฤษ รัสเซีย เวียดนาม ไทย โปรตุเกสแบบบราซิล ฝรั่งเศส ยูเครน สเปน ตุรกี ญี่ปุ่น และฮินดี ใช้ลิงก์ด้านบนเพื่อเปลี่ยนภาษา README

- เมื่อเปิดแอป จะเลือกภาษาที่ใช้แสดงผลหลักของระบบ หากอ่านไม่ได้หรือไม่รองรับ จะใช้ภาษาอังกฤษ
- ตัวเลือกมุมขวาบนเปลี่ยนภาษาได้ทันที การเลือกด้วยตนเองจะบันทึกในเครื่องและมีลำดับความสำคัญสูงกว่าในการเปิดครั้งต่อไป
- ภาษาของแอปแยกจากภาษาและเขตเวลาของลายนิ้วมือโปรไฟล์ ชื่อ หมายเหตุ แท็ก และการแก้ไขที่ยังไม่บันทึกจะคงเดิม
- คำแปลมาพร้อมแอป ไม่ต้องใช้บริการแปลออนไลน์ ดู[คู่มือการแปลภาษาจีนและอังกฤษ](docs/localization.md) หากต้องการมีส่วนร่วม

## ดาวน์โหลดและเริ่มใช้งาน

ดาวน์โหลดจาก [Releases](../../releases): macOS เลือก DMG หรือ ZIP ส่วน Windows เลือกตัวติดตั้งหรือรุ่น Portable แพ็กเกจที่เผยแพร่มีเอนจินลายนิ้วมือ Chromium 144 พร้อมใช้ ผู้ใช้ทั่วไปไม่ต้องคอมไพล์ Chromium เอง

หากระบบบล็อกรุ่นที่ไม่ได้ลงนาม ให้ยืนยันการเปิดใน **การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย** บน macOS หรือเลือก **ข้อมูลเพิ่มเติม → เรียกใช้ต่อไป** ใน SmartScreen บน Windows ดาวน์โหลดจาก Releases ของโครงการนี้เท่านั้น และตรวจสอบ SHA-256 เทียบกับค่าที่เผยแพร่

1. เปิด Prism Browser และสร้างโปรไฟล์ใหม่
2. ตั้งชื่อและเลือกระบบ ภาษา เขตเวลา หน้าจอ และข้อมูลประจำตัวฮาร์ดแวร์
3. ใช้การเชื่อมต่อโดยตรงหากไม่ต้องการพร็อกซี มิฉะนั้นให้กรอกโปรโตคอล โฮสต์ พอร์ต และข้อมูลรับรอง แล้วทดสอบการเชื่อมต่อ
4. บันทึกและเปิดโปรไฟล์ เมื่อปิดหน้าต่าง คุกกี้ แคช บุ๊กมาร์ก และข้อมูลส่วนขยายจะยังคงอยู่

แต่ละโปรไฟล์ใช้โฟลเดอร์ข้อมูลแยกกัน การทำสำเนาจะคงการตั้งค่าไว้ แต่สร้างตัวตนและค่าเริ่มต้นสำหรับการสร้างลายนิ้วมือ (seed) ใหม่

## ฟีเจอร์

ทุกอย่างทำงานบนเครื่องของคุณ ไม่มีบัญชี การสมัครสมาชิก หรือการเปิดใช้งาน API ระบบอัตโนมัติในเครื่อง งานตามกำหนดเวลา และการควบคุม AI ผ่าน MCP รวมอยู่ในเวอร์ชันฟรี และเคอร์เนลลายนิ้วมือมาพร้อมแอป

Community มีโปรไฟล์ในเครื่องไม่จำกัด ข้อมูลแยกกัน พร็อกซี HTTP/HTTPS/SOCKS5 และการป้องกัน WebRTC รั่วไหล สามารถตั้งค่า User-Agent ภาษา เขตเวลา หน้าจอ CPU หน่วยความจำ และ GPU โดยรักษาความสอดคล้องของ Canvas, WebGL, Audio, DOMRect, แบบอักษร, Speech และ WebGPU

รองรับการทำสำเนา กลุ่ม แท็ก รายการโปรด การทำงานแบบกลุ่ม ถังขยะ และการย้ายคุกกี้ โปรไฟล์ หรือพื้นที่ทำงานทั้งหมดภายในเครื่อง ไอคอน Dock ของ macOS และแถบงาน Windows สามารถแสดงหมายเลขโปรไฟล์ได้

## การตรวจสอบ

โครงการใช้ Pixelscan, CreepJS, BrowserLeaks, IPhey รวมถึงเมทริกซ์ลายนิ้วมือและเครื่องมือตรวจข้อมูลโปรไฟล์ของ Prism เพื่อตรวจความสอดคล้องของตัวตน ความคงที่เมื่อเปิดใหม่ด้วย seed เดิม การแยก seed ต่างกัน ความสอดคล้องระหว่าง iframe/Worker และการเก็บข้อมูลถาวร

การทดสอบของบุคคลที่สามเปลี่ยนแปลงได้ จึงไม่รับประกันว่าจะผ่านทุกการทดสอบตลอดไป คุณภาพพร็อกซี ความน่าเชื่อถือ IP การใช้เดสก์ท็อประยะไกล แบบอักษร และฮาร์ดแวร์จริงมีผลต่อผลลัพธ์เช่นกัน

## การพัฒนาและบิลด์

ต้องใช้ Node.js 22 ขึ้นไป npm และเครื่องมือบิลด์พื้นฐานของแพลตฟอร์ม เรียกใช้จากโฟลเดอร์รากของคลังโค้ด:

```bash
# ติดตั้ง ตรวจสอบ และบิลด์
npm ci
npm run typecheck
npm run build

# โหมดพัฒนา
npm run dev

# แพ็กเกจ macOS
npm run dist:mac

# แพ็กเกจ Windows
npm run dist:win
```

คำสั่งสร้างแพ็กเกจนี้ไม่รวมเอนจินลายนิ้วมือ หากบิลด์ Chromium 144 แนะนำ RAM 32 GB พื้นที่ SSD ว่างประมาณ 300 GB และพาธสั้นที่ไม่มีช่องว่าง

- macOS arm64: ต้องมี Xcode, Git, Python 3, Ninja และโวลุ่ม APFS ยอมรับสิทธิ์การใช้งาน Xcode แล้วดู[คู่มือบิลด์](tools/macos-kernel/README.md)
- Windows x64: ต้องมี Windows 10/11, Visual Studio พร้อมเครื่องมือพัฒนาเดสก์ท็อป C++, Windows SDK, Git, Python 3 และโวลุ่ม NTFS แนะนำสภาพแวดล้อมเสมือน Python ที่สะอาด ดู[คู่มือบิลด์](tools/windows-kernel/README.md)

เวอร์ชันที่ตรึงไว้ คอมมิตต้นทาง ลำดับแพตช์ และ SHA-256 อยู่ใน `tools/kernel-lock.json` แพตช์ร่วมอยู่ใน `tools/kernel-patches` หากบิลด์หยุดกลางทาง ให้รัน `Build-Kernel` อีกครั้งเพื่อทำต่อ ผลลัพธ์อยู่ใน `artifacts/<version>-<platform>` ใต้โฟลเดอร์บิลด์ และบันทึกอยู่ใน `logs` ดูคำสั่งละเอียดเพิ่มเติมใน [README ภาษาอังกฤษ](README.md)

นำเข้าบิลด์ในหน้าจัดการเอนจินของ Prism: macOS เลือก `Chromium.app` ส่วน Windows เลือกโฟลเดอร์ที่มี `chrome.exe` ตรวจสอบก่อนเปิดใช้งานเอนจิน ข้อมูลและการตั้งค่าโปรไฟล์เดิมจะยังอยู่

## ความปลอดภัยและสัญญาอนุญาต

อย่าโพสต์รหัสเปิดใช้งาน รหัสผ่านพร็อกซี คุกกี้ ข้อมูลกระเป๋าเงิน กุญแจส่วนตัว หรือไฟล์วินิจฉัยที่มีข้อมูลส่วนบุคคลใน issue สาธารณะ แจ้งขั้นตอนทำซ้ำขั้นต่ำ รุ่น แพลตฟอร์ม และผลกระทบ โดยลบข้อมูลลับก่อน คะแนนทดสอบลายนิ้วมือที่เปลี่ยนไปไม่จำเป็นต้องเป็นช่องโหว่ โปรดระบุเว็บไซต์ เวลา รุ่นเอนจิน และรายการที่ไม่ผ่าน

โค้ดที่เป็นของ Prism Browser Community ใช้ [MIT License](LICENSE) ส่วน Chromium, Electron และองค์ประกอบอื่นใช้สัญญาอนุญาตของตน การแจกจ่าย Chromium ต้องคงไฟล์ `LICENSE`, `LICENSES` และประกาศที่จำเป็นไว้ สัญญาอนุญาตโค้ดไม่ได้ให้สิทธิ์เครื่องหมายการค้าของชื่อ โลโก้ หรือไอคอน Prism โดยอัตโนมัติ

ใช้โครงการเฉพาะการแยกเบราว์เซอร์ การทดสอบอัตโนมัติ การวิจัยความเป็นส่วนตัว และการจัดการบัญชีที่ถูกกฎหมายและได้รับอนุญาต พร้อมปฏิบัติตามข้อกำหนดเว็บไซต์และกฎหมายที่เกี่ยวข้อง
