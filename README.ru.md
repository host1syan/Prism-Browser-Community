Prism Browser — локальный менеджер профилей браузера на базе модифицированного Chromium с настройкой цифровых отпечатков. У каждого профиля свои cookie, кэш, данные расширений, настройки прокси и отпечатка. Это позволяет разделять несколько браузерных идентичностей.

По умолчанию профили, cookie, учётные данные прокси и история остаются на устройстве пользователя. Community бесплатна и не ограничивает число локальных профилей.

## Поддержка исходного кода

Репозиторий остаётся открытым для изучения, проверки и самостоятельной сборки. Начиная с `v0.3.17`, новые функции, исправления и исходный код продукта больше не синхронизируются сюда регулярно. Развитие приложения, движков, сборок для разных платформ и функций Pro значительно усложнило поддержку и тестирование нескольких веток.

В виде исключения перенесена общая поддержка языков из версии 0.3.19 и переведён существующий открытый интерфейс. Приватные компоненты среды выполнения Pro, сервисы лицензирования, новые функции Pro и закрытые настройки публикации не включены. Постоянная синхронизация исходного кода продукта не возобновляется.

Существующий код, история коммитов и предыдущие версии сохраняются. Новые возможности, исправления и установщики доступны на [официальном сайте](https://prismbrowser.app/) и в [Releases](../../releases).

## Языки

Интерфейс и README доступны на **13 языках**: упрощённом и традиционном китайском, английском, русском, вьетнамском, тайском, бразильском португальском, французском, украинском, испанском, турецком, японском и хинди. Язык README выбирается по ссылкам вверху.

- При запуске используется основной язык интерфейса системы. Если он недоступен или не поддерживается, выбирается английский.
- Переключатель справа вверху меняет язык сразу. Ручной выбор сохраняется локально и имеет приоритет при следующих запусках.
- Язык приложения не меняет язык отпечатка и часовой пояс профиля. Имена, заметки, метки и несохранённые изменения остаются прежними.
- Переводы встроены в приложение, онлайн-перевод не используется. Для участия см. [руководство по локализации на китайском и английском](docs/localization.md).

## Установка и начало работы

В [Releases](../../releases) выберите DMG или ZIP для macOS, установщик или Portable для Windows. Опубликованные пакеты содержат готовый движок Chromium 144 с поддержкой отпечатков; самостоятельно собирать Chromium не требуется.

Если система блокирует неподписанную сборку, подтвердите открытие в разделе **Системные настройки → Конфиденциальность и безопасность** на macOS или выберите **Подробнее → Выполнить в любом случае** в SmartScreen на Windows. Скачивайте только из Releases проекта и сверяйте SHA-256 с опубликованным значением.

1. Откройте Prism Browser и создайте профиль.
2. Укажите имя, систему, язык, часовой пояс, экран и аппаратную идентичность.
3. Без прокси используйте прямое соединение. Иначе задайте протокол, адрес, порт и учётные данные, затем проверьте соединение.
4. Сохраните и откройте профиль. После закрытия окна его cookie, кэш, закладки и данные расширений сохранятся.

Каждый профиль имеет отдельный каталог данных. Дублирование сохраняет настройки, но создаёт новую идентичность и новое начальное значение генератора — seed.

## Возможности

Все функции работают локально: нет учётной записи, подписки или активации. Локальный API автоматизации, задачи по расписанию и локальное управление ИИ через MCP входят в бесплатную сборку, а ядро отпечатков поставляется вместе с приложением.

Community предлагает неограниченное число локальных профилей, изолированные данные, прокси HTTP/HTTPS/SOCKS5 и защиту от утечек WebRTC. Настраиваются User-Agent, язык, часовой пояс, экран, CPU, память и GPU; поддерживается согласованность Canvas, WebGL, Audio, DOMRect, шрифтов, Speech и WebGPU.

Есть дублирование, группы, метки, избранное, пакетные действия, корзина и локальный перенос cookie, профилей или всего рабочего пространства. Значки в Dock macOS и панели задач Windows могут отображать номер профиля.

## Проверки

Используются Pixelscan, CreepJS, BrowserLeaks, IPhey, матрица отпечатков Prism и аудит данных профилей. Проверяются согласованность идентичности, стабильность после перезапуска с тем же seed, различия между seed, согласованность iframe/Worker и сохранность данных.

Сторонние тесты меняются, поэтому прохождение всех проверок навсегда не гарантируется. На результат влияют качество прокси, репутация IP, удалённый рабочий стол, шрифты и реальное оборудование.

## Разработка и сборка

Нужны Node.js 22 или новее, npm и инструменты сборки вашей платформы. Выполните в корне репозитория:

```bash
# Установка, проверка и сборка
npm ci
npm run typecheck
npm run build

# Режим разработки
npm run dev

# Пакет для macOS
npm run dist:mac

# Пакет для Windows
npm run dist:win
```

Эти команды упаковки не включают движок отпечатков. Для сборки Chromium 144 рекомендуются 32 ГБ RAM, около 300 ГБ свободного SSD и короткий путь без пробелов.

- macOS arm64: Xcode, Git, Python 3, Ninja и том APFS. Примите лицензию Xcode; см. [руководство по сборке](tools/macos-kernel/README.md).
- Windows x64: Windows 10/11, Visual Studio с разработкой классических приложений на C++, Windows SDK, Git, Python 3 и том NTFS. Рекомендуется чистое виртуальное окружение Python; см. [руководство](tools/windows-kernel/README.md).

Версии, исходные коммиты, порядок патчей и SHA-256 указаны в `tools/kernel-lock.json`, общие патчи — в `tools/kernel-patches`. Для продолжения прерванной сборки повторно запустите `Build-Kernel`. Результаты находятся в `artifacts/<version>-<platform>` внутри каталога сборки, журналы — в `logs`. Подробные команды также есть в [английском README](README.md).

В менеджере движков Prism импортируйте локальную сборку: `Chromium.app` на macOS или каталог с `chrome.exe` на Windows. Проверьте движок и активируйте его. Данные и настройки существующих профилей сохраняются.

## Безопасность и лицензия

Не публикуйте в issues коды активации, пароли прокси, cookie, сведения о кошельках, приватные ключи или диагностику с персональными данными. Укажите минимальные шаги воспроизведения, версию, платформу и влияние, удалив конфиденциальные сведения. Изменение оценки отпечатка не обязательно означает уязвимость; укажите сайт, время проверки, версию движка и проблемные поля.

Собственный код Prism Browser Community распространяется по [лицензии MIT](LICENSE). Chromium, Electron и другие компоненты сохраняют свои лицензии. При распространении Chromium необходимо сохранять обязательные `LICENSE`, `LICENSES` и уведомления. Лицензия кода не предоставляет автоматически права на товарные знаки, название, логотип и значки Prism.

Используйте проект только для законной и разрешённой изоляции браузеров, автоматизированного тестирования, исследования приватности и управления аккаунтами, соблюдая условия сайтов и местное законодательство.
