Prism Browser, अनुकूलित Chromium पर आधारित एक स्थानीय ब्राउज़र प्रोफ़ाइल प्रबंधक है, जिसमें ब्राउज़र फ़िंगरप्रिंट कॉन्फ़िगर किए जा सकते हैं। हर प्रोफ़ाइल की कुकी, कैश, एक्सटेंशन डेटा, प्रॉक्सी सेटिंग और फ़िंगरप्रिंट अलग होते हैं, ताकि कई ब्राउज़र पहचानें एक-दूसरे से अलग रखी जा सकें।

डिफ़ॉल्ट रूप से प्रोफ़ाइल, कुकी, प्रॉक्सी के क्रेडेंशियल और ब्राउज़िंग इतिहास उपयोगकर्ता के अपने डिवाइस पर रहते हैं। Community संस्करण मुफ़्त है और स्थानीय प्रोफ़ाइल की संख्या सीमित नहीं करता।

## सोर्स कोड का रखरखाव

यह रिपॉज़िटरी सीखने, समीक्षा और समुदाय द्वारा बिल्ड बनाने के लिए सार्वजनिक रहेगी। `v0.3.17` से उत्पाद की नई सुविधाएँ, सुधार और सोर्स कोड में बदलाव यहाँ नियमित रूप से सिंक नहीं किए जाते। ऐप, ब्राउज़र इंजन, अलग-अलग प्लेटफ़ॉर्म के पैकेज और Pro सुविधाओं की बढ़ती जटिलता के कारण कई ब्रांच का रखरखाव और परीक्षण अधिक मेहनत माँगता है।

इस बार अपवाद के रूप में 0.3.19 का सामान्य बहुभाषी समर्थन यहाँ लाया गया है और मौजूदा सार्वजनिक इंटरफ़ेस का अनुवाद किया गया है। इसमें Pro के निजी रनटाइम, लाइसेंसिंग सेवाएँ, नई Pro सुविधाएँ या निजी प्रकाशन सेटिंग शामिल नहीं हैं। इसका अर्थ उत्पाद के सोर्स कोड का नियमित सिंक फिर से शुरू होना नहीं है।

मौजूदा कोड, कमिट इतिहास और पुराने रिलीज़ बने रहेंगे। नई सुविधाओं, सुधारों और इंस्टॉलर के लिए [आधिकारिक वेबसाइट](https://prismbrowser.app/) और [Releases](../../releases) देखें।

## भाषाएँ

इंटरफ़ेस और README **13 भाषाओं** में उपलब्ध हैं: सरलीकृत चीनी, पारंपरिक चीनी, अंग्रेज़ी, रूसी, वियतनामी, थाई, ब्राज़ीली पुर्तगाली, फ़्रेंच, यूक्रेनी, स्पैनिश, तुर्की, जापानी और हिन्दी। README की भाषा बदलने के लिए ऊपर दिए गए लिंक इस्तेमाल करें।

- शुरू होने पर ऐप सिस्टम की प्राथमिक डिस्प्ले भाषा चुनता है। भाषा उपलब्ध न होने या समर्थित न होने पर अंग्रेज़ी इस्तेमाल होती है।
- ऊपर दाईं ओर का चयनकर्ता तुरंत भाषा बदलता है। हाथ से किया गया चयन स्थानीय रूप से सहेजा जाता है और अगली बार उसी को प्राथमिकता मिलती है।
- इंटरफ़ेस की भाषा, प्रोफ़ाइल के फ़िंगरप्रिंट की भाषा और समय क्षेत्र से स्वतंत्र है। नाम, नोट, टैग और बिना सहेजे बदलाव सुरक्षित रहते हैं।
- अनुवाद ऐप के साथ आते हैं; ऑनलाइन अनुवाद सेवा की आवश्यकता नहीं है। योगदान के लिए [चीनी और अंग्रेज़ी में स्थानीयकरण मार्गदर्शिका](docs/localization.md) देखें।

## डाउनलोड और शुरुआत

[Releases](../../releases) से macOS के लिए DMG या ZIP, और Windows के लिए इंस्टॉलर या Portable संस्करण डाउनलोड करें। प्रकाशित पैकेज में तैयार Chromium 144 फ़िंगरप्रिंट इंजन शामिल है; सामान्य उपयोग के लिए Chromium स्वयं कंपाइल करना आवश्यक नहीं है।

अगर सिस्टम बिना हस्ताक्षर वाले बिल्ड को रोकता है, तो macOS में **System Settings → Privacy & Security** से खोलने की पुष्टि करें। Windows SmartScreen में **More info → Run anyway** चुनें। केवल इस परियोजना के Releases से डाउनलोड करें और SHA-256 का मिलान प्रकाशित मान से करें।

1. Prism Browser खोलकर नई प्रोफ़ाइल बनाएँ।
2. नाम भरें और सिस्टम, भाषा, समय क्षेत्र, स्क्रीन तथा हार्डवेयर पहचान चुनें।
3. प्रॉक्सी की आवश्यकता न हो तो सीधा कनेक्शन रखें। अन्यथा प्रोटोकॉल, होस्ट, पोर्ट और क्रेडेंशियल भरकर कनेक्शन जाँचें।
4. प्रोफ़ाइल सहेजें और खोलें। विंडो बंद करने पर भी उसकी कुकी, कैश, बुकमार्क और एक्सटेंशन डेटा बने रहते हैं।

हर प्रोफ़ाइल की अलग डेटा डायरेक्टरी होती है। डुप्लिकेट बनाने पर सेटिंग सुरक्षित रहती हैं, लेकिन नई पहचान और नया शुरुआती मान (seed) बनता है।

## विशेषताएँ

सब कुछ स्थानीय मशीन पर चलता है: कोई खाता, सदस्यता या सक्रियण नहीं। स्थानीय ऑटोमेशन API, निर्धारित कार्य और MCP के ज़रिए स्थानीय AI नियंत्रण मुफ़्त संस्करण का हिस्सा हैं, और फ़िंगरप्रिंट कर्नेल ऐप के साथ आता है।

Community में असीमित स्थानीय प्रोफ़ाइल, स्वतंत्र डेटा, HTTP/HTTPS/SOCKS5 प्रॉक्सी और WebRTC लीक से सुरक्षा मिलती है। User-Agent, भाषा, समय क्षेत्र, स्क्रीन, CPU, मेमोरी और GPU पहचान कॉन्फ़िगर की जा सकती है। Canvas, WebGL, Audio, DOMRect, फ़ॉन्ट, Speech और WebGPU की जानकारी में संगति रखी जाती है।

डुप्लिकेट, समूह, टैग, पसंदीदा, सामूहिक कार्रवाई, ट्रैश और कुकी, प्रोफ़ाइल या पूरे कार्यक्षेत्र का स्थानीय स्थानांतरण उपलब्ध है। macOS Dock और Windows टास्कबार के आइकन पर प्रोफ़ाइल नंबर दिखाया जा सकता है।

## सत्यापन

परियोजना Pixelscan, CreepJS, BrowserLeaks, IPhey, Prism फ़िंगरप्रिंट मैट्रिक्स और प्रोफ़ाइल डेटा ऑडिट का उपयोग करती है। इनमें पहचान की संगति, समान seed के साथ दोबारा शुरू करने पर स्थिरता, अलग seed के बीच भिन्नता, iframe/Worker की संगति और डेटा के सुरक्षित बने रहने की जाँच होती है।

तीसरे पक्ष के परीक्षण बदलते रहते हैं; हर परीक्षण में हमेशा सफल होने की गारंटी नहीं है। प्रॉक्सी की गुणवत्ता, IP की प्रतिष्ठा, रिमोट डेस्कटॉप, सिस्टम फ़ॉन्ट और वास्तविक हार्डवेयर भी परिणाम प्रभावित करते हैं।

## विकास और बिल्ड

Node.js 22 या नया, npm और प्लेटफ़ॉर्म के बुनियादी बिल्ड टूल चाहिए। रिपॉज़िटरी की रूट डायरेक्टरी से चलाएँ:

```bash
# इंस्टॉल, जाँच और बिल्ड
npm ci
npm run typecheck
npm run build

# विकास मोड
npm run dev

# macOS पैकेज
npm run dist:mac

# Windows पैकेज
npm run dist:win
```

इन पैकेजिंग कमांड में फ़िंगरप्रिंट इंजन शामिल नहीं होता। Chromium 144 कंपाइल करने के लिए 32 GB RAM, लगभग 300 GB खाली SSD और बिना स्पेस वाला छोटा पाथ सुझाया जाता है।

- macOS arm64: Xcode, Git, Python 3, Ninja और APFS वॉल्यूम चाहिए। Xcode लाइसेंस स्वीकार करें और [बिल्ड मार्गदर्शिका](tools/macos-kernel/README.md) देखें।
- Windows x64: Windows 10/11, C++ डेस्कटॉप डेवलपमेंट सहित Visual Studio, Windows SDK, Git, Python 3 और NTFS वॉल्यूम चाहिए। साफ़ Python वर्चुअल एनवायरनमेंट सुझाया जाता है। [बिल्ड मार्गदर्शिका](tools/windows-kernel/README.md) देखें।

निश्चित संस्करण, मूल कमिट, पैच का क्रम और SHA-256 `tools/kernel-lock.json` में हैं; साझा पैच `tools/kernel-patches` में हैं। रुके हुए बिल्ड को जारी रखने के लिए `Build-Kernel` फिर चलाएँ। आउटपुट बिल्ड रूट के `artifacts/<version>-<platform>` में और लॉग `logs` में मिलते हैं। विस्तृत कमांड [अंग्रेज़ी README](README.md) में भी हैं।

Prism के इंजन प्रबंधन से स्थानीय बिल्ड आयात करें: macOS में `Chromium.app`, Windows में `chrome.exe` वाली डायरेक्टरी चुनें। इंजन सक्रिय करने से पहले जाँचें। मौजूदा प्रोफ़ाइल का डेटा और सेटिंग बने रहते हैं।

## सुरक्षा और लाइसेंस

सार्वजनिक issue में सक्रियण कोड, प्रॉक्सी पासवर्ड, कुकी, वॉलेट जानकारी, निजी कुंजी या व्यक्तिगत डेटा वाली डायग्नोस्टिक फ़ाइल न डालें। संवेदनशील जानकारी हटाकर समस्या दोहराने के न्यूनतम चरण, संस्करण, प्लेटफ़ॉर्म और प्रभाव बताएँ। फ़िंगरप्रिंट टेस्ट का स्कोर बदलना आवश्यक रूप से सुरक्षा खामी नहीं है; साइट, जाँच का समय, इंजन संस्करण और असफल फ़ील्ड भी बताएँ।

Prism Browser Community का अपना कोड [MIT License](LICENSE) के अंतर्गत है। Chromium, Electron और अन्य घटकों पर उनके अपने लाइसेंस लागू होते हैं। Chromium वितरित करते समय आवश्यक `LICENSE`, `LICENSES` और सूचनाएँ सुरक्षित रखें। कोड का लाइसेंस Prism के नाम, लोगो या आइकन के ट्रेडमार्क अधिकार अपने आप नहीं देता।

परियोजना का उपयोग केवल कानूनी और अधिकृत ब्राउज़र अलगाव, ऑटोमेशन परीक्षण, गोपनीयता शोध और खाता प्रबंधन के लिए करें तथा संबंधित साइटों की शर्तों और स्थानीय कानूनों का पालन करें।
