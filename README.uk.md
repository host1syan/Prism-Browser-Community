Prism Browser — локальний менеджер профілів браузера на основі модифікованого Chromium із налаштуванням цифрових відбитків. Кожен профіль має окремі cookie, кеш, дані розширень, параметри проксі та відбитка, що дозволяє розділяти кілька браузерних ідентичностей.

За замовчуванням профілі, cookie, облікові дані проксі та історія залишаються на пристрої користувача. Community безкоштовна й не обмежує кількість локальних профілів.

## Підтримка вихідного коду

Репозиторій залишиться відкритим для навчання, перевірки та самостійного збирання. Починаючи з `v0.3.17`, функції, виправлення й код продукту більше не синхронізуються сюди регулярно. Складність застосунку, рушіїв, пакетів для різних платформ і можливостей Pro збільшила витрати на підтримку та тестування кількох гілок.

Як виняток, це оновлення переносить загальну підтримку мов із версії 0.3.19 та перекладає наявний відкритий інтерфейс. Приватні компоненти середовища виконання Pro, сервіси ліцензування, нові можливості Pro та закриті параметри публікації не включено. Постійна синхронізація коду продукту не відновлюється.

Наявний код, історія комітів і попередні випуски зберігаються. Нові функції, виправлення та інсталятори доступні на [офіційному сайті](https://prismbrowser.app/) і в [Releases](../../releases).

## Мови

Інтерфейс і README доступні **13 мовами**: спрощеною й традиційною китайською, англійською, російською, в’єтнамською, тайською, бразильською португальською, французькою, українською, іспанською, турецькою, японською та гінді. Мову README можна змінити за посиланнями вгорі.

- Під час запуску використовується основна мова інтерфейсу системи. Якщо вона недоступна або не підтримується, обирається англійська.
- Перемикач угорі праворуч змінює мову одразу. Ручний вибір зберігається локально та має пріоритет під час наступних запусків.
- Мова застосунку не змінює мову відбитка чи часовий пояс профілю. Назви, нотатки, мітки та незбережені зміни залишаються незмінними.
- Переклади вбудовані, онлайн-переклад не використовується. Для участі дивіться [посібник із локалізації китайською та англійською](docs/localization.md).

## Завантаження та початок роботи

У [Releases](../../releases) виберіть DMG або ZIP для macOS, інсталятор або Portable для Windows. Опубліковані пакети містять готовий рушій Chromium 144 із підтримкою відбитків; самостійно збирати Chromium не потрібно.

Якщо система блокує непідписаний випуск, підтвердьте відкриття в **Системних параметрах → Приватність і безпека** на macOS або виберіть **Докладніше → Виконати в будь-якому разі** у SmartScreen на Windows. Завантажуйте лише з Releases цього проєкту та звіряйте SHA-256 з опублікованим значенням.

1. Відкрийте Prism Browser і створіть профіль.
2. Укажіть назву, систему, мову, часовий пояс, екран і апаратну ідентичність.
3. Без проксі використовуйте пряме з’єднання. Інакше вкажіть протокол, адресу, порт та облікові дані й перевірте з’єднання.
4. Збережіть і відкрийте профіль. Після закриття вікна cookie, кеш, закладки та дані розширень зберігаються.

Кожен профіль має окремий каталог даних. Дублювання зберігає налаштування, але створює нову ідентичність і нове початкове значення генератора — seed.

## Можливості

Усі функції працюють локально: немає облікового запису, підписки чи активації. Локальний API автоматизації, завдання за розкладом і локальне керування ШІ через MCP входять до безкоштовної збірки, а ядро відбитків постачається разом із застосунком.

Community пропонує необмежені локальні профілі, незалежні дані, проксі HTTP/HTTPS/SOCKS5 і захист від витоків WebRTC. Можна налаштовувати User-Agent, мову, часовий пояс, екран, CPU, пам’ять і GPU зі збереженням узгодженості Canvas, WebGL, Audio, DOMRect, шрифтів, Speech та WebGPU.

Доступні дублювання, групи, мітки, обране, пакетні дії, кошик і локальне перенесення cookie, профілів або всього робочого простору. Піктограми Dock у macOS і панелі завдань Windows можуть показувати номер профілю.

## Перевірки

Проєкт використовує Pixelscan, CreepJS, BrowserLeaks, IPhey, матрицю відбитків Prism та аудит даних профілів. Перевіряються узгодженість ідентичності, стабільність перезапуску з тим самим seed, відмінність між seed, узгодженість iframe/Worker і збереження даних.

Сторонні тести змінюються, тому проходження всіх перевірок назавжди не гарантується. На результати впливають якість проксі, репутація IP, віддалений робочий стіл, шрифти та реальне обладнання.

## Розробка та збирання

Потрібні Node.js 22 або новіший, npm та інструменти збирання вашої платформи. Виконайте в корені репозиторію:

```bash
# Встановлення, перевірка та збирання
npm ci
npm run typecheck
npm run build

# Режим розробки
npm run dev

# Пакет для macOS
npm run dist:mac

# Пакет для Windows
npm run dist:win
```

Ці команди пакування не включають рушій відбитків. Для збирання Chromium 144 рекомендовано 32 ГБ RAM, близько 300 ГБ вільного SSD і короткий шлях без пробілів.

- macOS arm64: Xcode, Git, Python 3, Ninja і том APFS. Прийміть ліцензію Xcode; дивіться [посібник зі збирання](tools/macos-kernel/README.md).
- Windows x64: Windows 10/11, Visual Studio з розробкою класичних застосунків на C++, Windows SDK, Git, Python 3 і том NTFS. Бажано чисте віртуальне середовище Python; дивіться [посібник](tools/windows-kernel/README.md).

Версії, вихідні коміти, порядок патчів і SHA-256 записані в `tools/kernel-lock.json`, спільні патчі — у `tools/kernel-patches`. Повторно запустіть `Build-Kernel`, щоб продовжити перерване збирання. Результати знаходяться в `artifacts/<version>-<platform>` у каталозі збирання, журнали — у `logs`. Докладні команди також є в [англійському README](README.md).

У менеджері рушіїв Prism імпортуйте локальну збірку: `Chromium.app` на macOS або каталог із `chrome.exe` на Windows. Перевірте рушій перед активацією; наявні дані та налаштування зберігаються.
