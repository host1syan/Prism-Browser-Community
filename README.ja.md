作者：[DFarm](https://x.com/DFarm_club) · 公式サイト：[prismbrowser.app](https://prismbrowser.app/)

Prism Browser は、カスタマイズした Chromium を基盤とするローカルのブラウザープロファイル管理ツールです。各プロファイルは Cookie、キャッシュ、拡張機能データ、プロキシ設定、フィンガープリント設定を個別に持ち、互いに分離されたブラウザーの識別情報を管理できます。

プロファイル、Cookie、プロキシ認証情報、閲覧履歴は、既定ではユーザー自身の端末に保存されます。Community 版は無料で、ローカルプロファイル数の制限はありません。

## ソースコードの保守方針

このリポジトリは、学習、レビュー、コミュニティによるビルドのために公開を継続します。`v0.3.17` 以降、製品版の新機能、修正、ソースコードの変更は、原則として定期的に同期しません。アプリ、ブラウザーエンジン、クロスプラットフォームのパッケージ、Pro 機能の複雑化により、複数ブランチの保守とテストの負担が増えたためです。

今回は例外として、0.3.19 の汎用的な多言語対応を移植し、既存の公開インターフェイスを翻訳しています。Pro の非公開ランタイム、ライセンスサービス、新しい Pro 機能、非公開のリリース設定は含まれません。製品版ソースコードの継続的な同期を再開するものではありません。

既存のコード、コミット履歴、過去のリリースは保持されます。今後の機能、修正、インストーラーは[公式サイト](https://prismbrowser.app/)と [Releases](../../releases) をご確認ください。

## 対応言語

アプリのインターフェイスと README は **13 言語**に対応しています。簡体字中国語、繁体字中国語、英語、ロシア語、ベトナム語、タイ語、ブラジルポルトガル語、フランス語、ウクライナ語、スペイン語、トルコ語、日本語、ヒンディー語です。README の言語はページ上部のリンクで切り替えられます。

- 起動時はシステムの優先表示言語に合わせます。未対応、または取得できない場合は英語を使用します。
- 右上の選択欄で即座に切り替えられます。手動で選んだ言語は端末に保存され、次回以降も優先されます。
- アプリの表示言語は、プロファイルのフィンガープリント言語やタイムゾーンとは独立しています。名前、メモ、タグ、未保存の編集内容は維持されます。
- 翻訳データはアプリに同梱され、オンライン翻訳は不要です。貢献方法は[多言語開発ガイド（中国語・英語）](docs/localization.md)をご覧ください。

## ダウンロードと使い方

[Releases](../../releases) から、macOS は DMG または ZIP、Windows はインストーラーまたは Portable 版をダウンロードしてください。公開パッケージには、すぐに利用できる Chromium 144 フィンガープリントエンジンが含まれます。通常の利用では Chromium のビルドは不要です。

未署名のビルドがブロックされた場合、macOS は「システム設定 → プライバシーとセキュリティ」で起動を確認し、Windows は SmartScreen の「詳細情報 → 実行」を選択します。本プロジェクトの Releases からのみ取得し、公開されている SHA-256 と照合してください。

1. Prism Browser を開き、新しいプロファイルを作成します。
2. 名前を入力し、必要な OS、言語、タイムゾーン、画面、ハードウェア識別情報を設定します。
3. プロキシが不要なら直接接続を使用します。必要な場合はプロトコル、ホスト、ポート、認証情報を入力し、接続をテストします。
4. 保存してプロファイルを開きます。ウィンドウを閉じても Cookie、キャッシュ、ブックマーク、拡張機能データは残ります。

各プロファイルには独立したデータディレクトリがあります。複製時は設定を引き継ぎ、新しい識別情報とシードを生成します。

## 機能

すべての機能はローカルで動作し、アカウント・サブスクリプション・アクティベーションはありません。ローカル自動化 API、スケジュールタスク、MCP によるローカル AI 制御は無償版に含まれ、指紋カーネルはアプリに同梱されます。

Community には、無制限のローカルプロファイル、独立したデータ、HTTP／HTTPS／SOCKS5 プロキシ、WebRTC 漏えい防止が含まれます。User-Agent、言語、タイムゾーン、画面、CPU、メモリ、GPU を設定でき、Canvas、WebGL、Audio、DOMRect、フォント、Speech、WebGPU の一貫性を維持します。

複製、グループ、タグ、お気に入り、一括操作、ごみ箱、Cookie・個別プロファイル・ワークスペース全体のローカル移行に対応します。macOS の Dock と Windows のタスクバーでは、アイコンにプロファイル番号を表示できます。

## 検証範囲

Pixelscan、CreepJS、BrowserLeaks、IPhey、Prism のフィンガープリントマトリクスとプロファイルデータ監査を使用し、識別情報の整合性、同じシードでの再起動の安定性、異なるシードの分離、iframe／Worker の一貫性、データの永続性を検証します。

外部テストは変化するため、すべてのテストに永久に合格する保証はありません。プロキシ品質、IP の評価、リモートデスクトップ、システムフォント、実際のハードウェアも結果に影響します。

## 開発とビルド

Node.js 22 以降、npm、各プラットフォームの基本ビルドツールが必要です。リポジトリのルートで実行してください。

```bash
# インストール・検査・ビルド
npm ci
npm run typecheck
npm run build

# 開発モード
npm run dev

# macOS パッケージ
npm run dist:mac

# Windows パッケージ
npm run dist:win
```

これらのパッケージ作成コマンドにはフィンガープリントエンジンは含まれません。Chromium 144 のビルドには、32 GB の RAM、約 300 GB の SSD 空き容量、空白を含まない短いパスを推奨します。

- macOS arm64：Xcode、Git、Python 3、Ninja、APFS ボリュームが必要です。Xcode のライセンスに同意し、[ビルドガイド](tools/macos-kernel/README.md)をご確認ください。
- Windows x64：Windows 10／11、Visual Studio の C++ デスクトップ開発環境、Windows SDK、Git、Python 3、NTFS ボリュームが必要です。クリーンな Python 仮想環境を推奨します。[ビルドガイド](tools/windows-kernel/README.md)をご確認ください。

固定バージョン、上流コミット、パッチ順序、SHA-256 は `tools/kernel-lock.json`、共通パッチは `tools/kernel-patches` にあります。中断したビルドは `Build-Kernel` を再実行して継続できます。成果物はビルドルートの `artifacts/<version>-<platform>`、ログは `logs` に出力されます。詳細なコマンドは [英語 README](README.md) にも記載しています。

アプリのエンジン管理からローカルビルドをインポートします。macOS は `Chromium.app`、Windows は `chrome.exe` を含むディレクトリを選択してください。検証後に有効化します。既存プロファイルのデータと設定は保持されます。

## セキュリティ報告とライセンス

有効化コード、プロキシのパスワード、Cookie、ウォレット情報、秘密鍵、個人情報を含む診断ファイルを公開 Issue に投稿しないでください。機密情報を取り除き、最小限の再現手順、バージョン、プラットフォーム、影響を記載してください。フィンガープリントのスコア変化は必ずしも脆弱性ではありません。検査サイト、日時、エンジンのバージョン、失敗した項目も添えてください。

合法かつ許可されたブラウザーの分離、自動化テスト、プライバシー研究、アカウント管理にのみ利用し、対象サイトの規約と適用法を遵守してください。
